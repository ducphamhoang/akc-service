### Task 2: Add _extract_entity_from_context helper to routes.py

<read_first>
- akc_service/api/routes.py (read imports section and get_active_patterns helper, lines 1-100)
</read_first>

<action>
Add helper function after the `get_active_patterns` function (after line ~97, before the `logger = ...` line):

```python
def _extract_entity_from_context(akc_context: dict) -> Optional[str]:
    """Extract entity name from akc_context for Tier 2 KB routing.

    Checks direct 'entity' key first, then falls back to the entity field
    of the first active pattern in knowledge_patterns_active.
    Returns None if no entity can be determined.
    """
    if not akc_context:
        return None
    entity = akc_context.get("entity")
    if entity:
        return str(entity)
    patterns = akc_context.get("knowledge_patterns_active", [])
    if patterns and isinstance(patterns, list) and patterns[0]:
        return patterns[0].get("entity")
    return None
```
</action>

<acceptance_criteria>
- routes.py contains `def _extract_entity_from_context(` function
- Function checks `akc_context.get("entity")` first
- Function falls back to `knowledge_patterns_active[0].get("entity")`
- Returns None if akc_context is empty or falsy
</acceptance_criteria>
