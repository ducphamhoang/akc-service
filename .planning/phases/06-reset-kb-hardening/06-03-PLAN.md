<objective>
Add kb: Optional[str] to ResetRequest and wire resolve_kb_dir() through all downstream calls in reset_kb(). This fixes the CRITICAL correctness bug where reset_kb() always resets the default KB, ignoring multi-KB deployments.

Purpose: In deployments with multiple KB directories (AKC_SERVICE_KB_REGISTRY configured), operators need to target a specific KB for reset. Without the kb param, reset_kb() always operates on the default KB regardless of which KB the caller intends to restore.

Output: ResetRequest with kb field; reset_kb() using resolve_kb_dir(); set_escape_hatch() extended with optional kb_dir; tests covering the routing.
</objective>
